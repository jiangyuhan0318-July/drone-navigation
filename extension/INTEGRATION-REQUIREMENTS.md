## 4. 响应格式(我方消费的最终契约)

队友输出经我方适配服务规范化后, 统一为:

```json
{
  "state": "<上表语义值>",
  "confidence": 0.87,
  "features": {"<队友特征名>": <值>},
  "fresh_s": 0.03,
  "frames": 1234
}
```

- `confidence`: 0~1; 队友无置信度则置 1.0
- `fresh_s`: 距最后推理帧秒数; 队友输出带时间戳可算, 否则我方计时
- `features`: 队友输出中的可解释特征 (角度/坐标等), 便于调试, 可选
